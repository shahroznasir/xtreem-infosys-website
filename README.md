# XTREEM INFOSYS - Premium Corporate Website

A bespoke, ultra-premium, and modern corporate website built for **XTREEM INFOSYS** (New Delhi, India), specializing in IT Infrastructure Maintenance, Facility Management Services (FMS), Networking Solutions, and Multi-Vendor OEM Support.

---

## Key Features & Design System

1. **Brand Aesthetics & Color Palette**:
   - Deep Midnight Navy (`#040914`, `#081225`, `#0B1930`)
   - Metallic Brushed Gold & Champagne (`#D4AF37`, `#F3D079`, `#997312`)
   - Luminous Cyber Accents (`#38BDF8`)
   - Seamless **Dark & Light Mode Switcher** matching both Dark and Light brand logos.

2. **Interactive 60fps Visual Animations**:
   - **Interactive Cyber Network Canvas**: Real-time particle simulation of enterprise routers, server nodes, and traveling data packets.
   - **Live AMC & FMS Cost Estimator**: Interactive sliders for Laptops, Servers, and Networking devices with automatic SLA and pricing scope calculation.
   - **3D Perspective Tilt Cards**: Responsive mouse-tracking hover depth on service cards.
   - **Infinite Client Marquee**: Showcasing enterprise and public-sector clients (*Greenlam, Concentrix, C-DOT, RattanIndia Power, NIEPA, Sysnet, Neosky, Neotech*).
   - **Hardware Coverage Tabs**: Deep-dive technical matrix for Laptops, Desktops, Servers, AIOs, and Projectors.
   - **Statutory Transparency Card**: GSTIN, PAN, Bank of Baroda details with 1-click clipboard copy.
   - **Interactive Service Detail Modals**: Comprehensive popup specs for each service vertical.
   - **Direct Inquiry & Floating CTA**: Instant WhatsApp messaging, Phone dialer, and RFP proposal request form.

Double-click or open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).

